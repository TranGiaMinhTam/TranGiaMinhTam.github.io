U-01 establishes an inactive, recoverable foundation for the science, data science, and bioinformatics portfolio redesign. It preserves the rejected application, adapts verified Minh Tam data into typed immutable records, gates evidence through an explicit curated manifest, provides deterministic validation and accessible visualization contracts, and introduces semantic primitives and light/dark scientific design tokens without switching the live app.
